# Overview

Compass Assistant is an in-app network of AI agents and tools you can access through a single chat experience in Recurly. Use it as your on-demand co-pilot to navigate Revenue Recognition (RevRec) tasks, search helpful resources, and take action using natural language.

### Required plan

This feature or setting is available to all customers on any Recurly subscription plan.

# Definition

Compass Assistant is a unified chat interface in Recurly that helps you find answers, stay oriented in RevRec workflows, and move faster by letting you ask questions the way you’d ask a teammate.

# Key benefits

* **Find answers faster**: Search across docs, knowledge base content, and API snippets from one place
* **Stay in flow**: Ask follow-up questions without restarting your search
* **Keep work organised**: Maintain multiple conversation threads for different tasks, audits, or investigations

# Key details

## Get started

To open Compass Assistant, select the sparkles icon in the bottom-right corner of your Recurly dashboard.

## Interaction basics

| What you can do         | How it works                                                                       |
| ----------------------- | ---------------------------------------------------------------------------------- |
| Ask follow-up questions | Keep the conversation going to refine results without repeating your full question |
| Use feedback controls   | Select the thumbs up or thumbs down icons to help improve accuracy over time       |

## Conversational search and knowledge sources

Compass Assistant is optimised to help you find RevRec answers quickly by searching multiple sources at once:

* Product documentation (feature overviews and setup guides)
* Knowledge base articles (troubleshooting and best practices)
* API snippets (functional examples for API calls)

## Manage your conversations

Use conversation threads to keep different workstreams separate, so you can switch between tasks without losing context.

| Task              | What to do                     | What to expect                                                       |
| ----------------- | ------------------------------ | -------------------------------------------------------------------- |
| Start a new chat  | Select **New chat**            | Clears the current context so you can switch topics cleanly          |
| View chat history | Open **Chat history**          | See a chronological list of past conversations for easy reference    |
| Resume a thread   | Select a previous conversation | Reloads that thread’s context so you can continue where you left off |

# FAQs

**Q: Does Compass Assistant remember what I said earlier?**
**A**: It remembers the context within the conversation thread you’re in. If you start a new chat, the assistant won’t use the previous thread’s context.

**Q: How can I help improve results?**
**A:** Use the thumbs up or thumbs down icons after a response. Your feedback helps refine accuracy and relevance.
