# Editing currencies configuration

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">1</div>
    <div><h4>Navigate to Currencies</h4><p>Go to Setup → Currencies.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/4ae93a3-image.png" align="center" width="75%" border={true} />


All currencies are predefined in Recurly RevRec. To edit one:

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">2</div>
    <div><h4>Open the field</h4><p>Double-click the currency or precision field you want to edit.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">3</div>
    <div><h4>Make your changes</h4><p>Update the field with the value you need.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">4</div>
    <div><h4>Save</h4><p>Select the Save icon.</p></div>
  </div>
</div>
