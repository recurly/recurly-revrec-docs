# Configuring profiles

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">1</div>
    <div><h4>Navigate to Profiles</h4><p>Go to Set Up → Profiles.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/8ea6717-image.png" align="center" width="75%" border={true} />


<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">2</div>
    <div><h4>Set your profile options</h4><p>Configure the fields below to match your organization's requirements.</p></div>
  </div>
</div>

<ul class="rp-list">
  <li><strong>Account separator:</strong> Specifies the value used for account separation.</li>
  <li><strong>Commission only:</strong> Indicates whether only commission data is present.</li>
  <li><strong>Global currency:</strong> Designates the primary currency for financial reporting.</li>
  <li><strong>Overage allowed:</strong> Enable this if invoicing above the transaction amount is allowed.</li>
  <li><strong>Contract revision level:</strong> Determines when a contract alteration counts as a Contract Modification.</li>
  <li><strong>Revenue duration:</strong> Differentiates between short-term (within a year) and long-term (beyond a year) revenue for GAAP and IFRS disclosure.</li>
  <li><strong>SSP date:</strong> When configured in the profile, Recurly RevRec sets the SSP date for all transaction lines to the earliest sales order book date.</li>
</ul>

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">3</div>
    <div><h4>Save your settings</h4><p>Once you've finalized your profile settings, select the Save icon.</p></div>
  </div>
</div>
