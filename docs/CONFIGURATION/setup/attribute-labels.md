# Key details

Attribute labels are organized under four main tabs:

<div class="rp-nav-grid">

<Cards>
  <Card title="Contracts">
    Pertains to contracts and sales orders.
  </Card>
  <Card title="Documents">
    Relates to documents and invoices.
  </Card>
  <Card title="Cost">
    Concerns cost, expenses, and commissions.
  </Card>
  <Card title="Outbound attributes">
    Defines how data is relayed to your ERP system.
  </Card>
</Cards>

</div>

<div class="rp-callout rp-callout-note">
  <div><strong><i class="fa-solid fa-circle-info" aria-hidden="true"></i> Note</strong>Attributes must be defined here for Recurly RevRec to gather data.</div>
</div>
