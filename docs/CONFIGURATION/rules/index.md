### Limitations

<div class="rp-callout rp-callout-warning">
  <div><strong><i class="fa-solid fa-triangle-exclamation" aria-hidden="true"></i> Before you configure</strong>Keep these hard constraints in mind across the Rules section:
    <ul>
      <li>Once a Contract Grouping rule is created, it can't be deleted — it can only be inactivated.</li>
      <li>Approved SSP data can't be deleted.</li>
      <li>Holds, once applied, can only be released based on the configured criteria or manually by authorized personnel.</li>
    </ul>

# Definition

<div class="rp-definition">The Rules section in Recurly RevRec offers a suite of tools for contract grouping, performance obligation management, standalone selling price determination, variable consideration handling, cost allocation, holds management, and additional journals management. Together, these tools let you craft a tailored set of rules that ensures accurate, compliant revenue recognition across your business.</div>
