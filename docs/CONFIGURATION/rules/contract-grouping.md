# Configuring a Contract Grouping rule

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">1</div>
    <div><h4>Open Contract Grouping</h4><p>Navigate to the Rules section and select "Contract Grouping."</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">2</div>
    <div><h4>Start a new rule</h4><p>Select the "+" icon in the right menu to create a new grouping rule.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/73e91e0-image.png" align="center" width="75%" border={true} />


<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">3</div>
    <div><h4>Name and date the rule</h4><p>Provide a name for the contract grouping rule and specify its active date.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/7609ae3-image.png" align="center" width="75%" border={true} />


<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">4</div>
    <div><h4>Add grouping criteria</h4><p>Under the Grouping section, select the "+" button to add grouping criteria.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/37d95e4-image.png" align="center" width="75%" border={true} />


<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">5</div>
    <div><h4>Select grouping attributes</h4><p>Select the grouping attribute or attributes that define how contracts should be grouped.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">6</div>
    <div><h4>Set the rolling window</h4><p>Specify the rolling date and the number of days for the grouping rule.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/0aa6811-image.png" align="center" width="75%" border={true} />


<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">7</div>
    <div><h4>Save</h4><p>Save your configuration.</p></div>
  </div>
</div>

# Inactivating a Contract Grouping rule

<div class="rp-callout rp-callout-note">
  <div><strong><i class="fa-solid fa-circle-info" aria-hidden="true"></i> Note</strong>Once a Contract Grouping rule is created, it can't be deleted. You can inactivate a grouping rule instead, if needed.</div>
</div>

To inactivate a grouping rule:

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">1</div>
    <div><h4>Select the rule</h4><p>Go to the Contract Grouping section and select the grouping rule tab you want to inactivate.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">2</div>
    <div><h4>Change the status</h4><p>The rule's current status is "active." Change it to "inactive."</p></div>
  </div>
</div>


<Image src="https://files.readme.io/8c5328f-image.png" align="center" width="75%" border={true} />


<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">3</div>
    <div><h4>Save</h4><p>Select the Save icon to save your changes.</p></div>
  </div>
</div>

<ul class="rp-list">
  <li>Only active grouping rules appear in the Contract Grouping section.</li>
  <li>Once a grouping rule is inactivated, it moves to the inactive tab for reference.</li>
  <li>An inactive grouping rule can't be made active again.</li>
</ul>
