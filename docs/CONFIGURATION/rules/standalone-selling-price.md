  <div class="rp-overview">Setting up Standalone Selling Price (SSP) is a three-step process: create the SSP by defining values, pricing attributes, and any adjustments or discounts; set up SSP Analyzer rules to identify and analyze SSP variances; then prepare and upload your data for processing. Follow these steps and you'll have a robust SSP framework tailored to your products or services.</div>

# Creating the SSP

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">1</div>
    <div><h4>Open SSP Definition</h4><p>Navigate to the Rules section and select SSP Definition.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/7bdf656-image.png" align="center" width="75%" border={true} />


<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">2</div>
    <div><h4>Start a new SSP</h4><p>Select the "+" icon to create a new SSP.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/50c8572-image.png" align="center" width="75%" border={true} />


<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">3</div>
    <div><h4>Name the SSP</h4><p>Enter a name for the SSP.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">4</div>
    <div><h4>Leave the Range tab blank</h4><p>Leave the Range tab blank when uploading SSP data.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">5</div>
    <div><h4>Select the SSP type</h4><p>Select SSP or RSSP as the Type.</p></div>
  </div>
</div>

<div class="rp-callout rp-callout-note">
  <div><strong><i class="fa-solid fa-circle-info" aria-hidden="true"></i> Note</strong>Select SSP if you want to define a standalone selling price, or RSSP if you want to define a residual standalone selling price.</div>
</div>

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">6</div>
    <div><h4>Choose the book</h4><p>Under the Books tab, choose the relevant book for the SSP.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/ad342cf-image.png" align="center" width="75%" border={true} />


<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">7</div>
    <div><h4>Select the SSP value</h4><p>Select the appropriate SSP value from the dropdown menu.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/0695b7d-image.png" align="center" width="75%" border={true} />


<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">8</div>
    <div><h4>Set the SSP statistic</h4><p>Specify the SSP statistic: Simple Median, Simple Average, Weighted Median, or Weighted Average.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/886d8aa-image.png" align="center" width="75%" border={true} />


<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">9</div>
    <div><h4>Set the SSP base</h4><p>Determine the SSP base: Low, Median, High, or Follow SellPrice.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/b2875c5-image.png" align="center" width="75%" border={true} />

    <div class="rp-step-num">10</div>

# Configuring the SSP Analyzer for data upload

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">1</div>
    <div><h4>Open SSP Analyzer</h4><p>Navigate to the Rules section and select SSP Analyzer, or select SSP Analyzer at the top of the SSP page. If you have multiple SSP definitions, go to the SSP card you need and select SSP Analyzer from there.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/d108a7b-image.png" align="center" width="75%" border={true} />


<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">2</div>
    <div><h4>Start a new SSP Analyzer</h4><p>On the SSP Analyzer page, select the "+" icon to create a new SSP Analyzer.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/dc0b6d1-image.png" align="center" width="75%" border={true} />


<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">3</div>
    <div><h4>Name the analyzer</h4><p>Provide a unique name for the SSP Analyzer.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">4</div>
    <div><h4>Select the analyzer type</h4><p>Select Rules as the Analyzer Type if you're uploading SSP data.</p></div>

  <div class="rp-step">

# Preparing and uploading SSP data

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">1</div>
    <div><h4>Confirm your data matches</h4><p>Make sure the information in your table matches the selections you made for the SSP configuration, including the value type (amount or percentage).</p></div>
  </div>
</div>


<Image src="https://files.readme.io/1ada774-image.png" align="center" width="75%" border={true} />


<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">2</div>
    <div><h4>Upload the file</h4><p>Select the Upload icon, choose the SSP file you want to upload in the SSP upload window, then select Open.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">3</div>
    <div><h4>Save</h4><p>Once the SSP file is uploaded, select the Save icon. The uploaded data appears under the Rules section in SSP Analyzer.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">4</div>
    <div><h4>Approve the data</h4><p>Select the Approve icon to approve the uploaded SSP data. The Flow Status changes to Approved once approval is complete.</p></div>
  </div>
</div>


<Image src="https://files.readme.io/c3025e9-image.png" align="center" width="75%" border={true} />


<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">5</div>
    <div><h4>Download the data (optional)</h4><p>Once your SSP data is approved, you can select the Download icon to download it.</p></div>
  </div>
</div>

<div class="rp-callout rp-callout-warning">
  <div><strong><i class="fa-solid fa-triangle-exclamation" aria-hidden="true"></i> Warning</strong>You can only delete SSP data before it's approved — select the Delete icon to remove it. Once approved, the data can't be deleted. If approved data won't be used going forward, specify an end date so it stops being used beyond that date. Recurly RevRec lets you set validity for uploaded SSP data by specifying start and end dates for the approved data.</div>
</div>

# SSP analysis by the system

If you select Analysis as the Analyzer Type for the SSP Analyzer, the system collects data automatically based on your configuration, rather than requiring a manual data upload.

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">1</div>
    <div><h4>Open SSP Analyzer</h4><p>Navigate to the Rules section and select SSP Analyzer, or select SSP Analyzer at the top of the SSP page. If you have multiple SSP definitions, go to the SSP card you need and select SSP Analyzer from there.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">2</div>
    <div><h4>Start a new SSP Analyzer</h4><p>Select the "+" icon to create a new SSP Analyzer.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">3</div>
    <div><h4>Name the analyzer</h4><p>Provide a unique name for the SSP Analyzer.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">4</div>
    <div><h4>Select the analyzer type</h4><p>Select Analysis as the Analyzer Type.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">5</div>
    <div><h4>Set the active dates</h4><p>Define the active dates for the SSP data, including a start date and, if applicable, an end date.</p></div>
  </div>
</div>

<div class="rp-callout rp-callout-note">
  <div><strong><i class="fa-solid fa-circle-info" aria-hidden="true"></i> Note</strong>Fields like range, type, stats, value, and base appear as configured when you set up the SSP — you can't change them here.</div>
</div>

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">6</div>
    <div><h4>Add criteria</h4><p>Add the criteria that defines the data to include when deriving SSP values — for example, a book date greater than a certain threshold.</p></div>
  </div>
  <div class="rp-step">
    <div class="rp-step-num">7</div>
    <div><h4>Run the analysis</h4><p>Select the analysis icon. The system collects all data matching your criteria and returns the SSP breakup based on your grouping.</p></div>
  </div>
</div>

If your SSP grouping is "Item," the collected data is spread into different rows based on that grouping — completing the data collection process.

<div class="rp-steps">
  <div class="rp-step">
    <div class="rp-step-num">8</div>
    <div><h4>Approve the SSP</h4><p>Approve the SSP to put it into use.</p></div>
  </div>
</div>
