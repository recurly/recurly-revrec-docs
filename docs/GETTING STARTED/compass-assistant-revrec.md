# Key details

## Get started

To open Compass Assistant, select the sparkles icon in the bottom-right corner of your Recurly dashboard.

## Interaction basics

<table class="rp-params">
  <tr class="rp-thead-row"><td>What you can do</td><td>How it works</td></tr>
  <tr><td>Ask follow-up questions</td><td>Keep the conversation going to refine results without repeating your full question.</td></tr>
  <tr><td>Use feedback controls</td><td>Select the thumbs up or thumbs down icons to help improve accuracy over time.</td></tr>
</table>

## Conversational search and knowledge sources

Compass Assistant is optimised to help you find RevRec answers quickly by searching multiple sources at once:

<ul class="rp-list">
  <li><strong>Product documentation:</strong> Feature overviews and setup guides.</li>
  <li><strong>Knowledge base articles:</strong> Troubleshooting and best practices.</li>
  <li><strong>API snippets:</strong> Functional examples for API calls.</li>
</ul>

## Manage your conversations

Use conversation threads to keep different workstreams separate, so you can switch between tasks without losing context.

<table class="rp-params">
  <tr class="rp-thead-row"><td>Task</td><td>What to do</td><td>What to expect</td></tr>
  <tr><td>Start a new chat</td><td>Select <strong>New chat</strong></td><td>Clears the current context so you can switch topics cleanly.</td></tr>
  <tr><td>View chat history</td><td>Open <strong>Chat history</strong></td><td>See a chronological list of past conversations for easy reference.</td></tr>
  <tr><td>Resume a thread</td><td>Select a previous conversation</td><td>Reloads that thread's context so you can continue where you left off.</td></tr>
</table>

# FAQ

<Accordion title="Does Compass Assistant remember what I said earlier?">
  It remembers the context within the conversation thread you're in. If you start a new chat, the assistant won't carry over the previous thread's context.
</Accordion>

<Accordion title="How can I help improve results?">
  Use the thumbs up or thumbs down icons after a response. Your feedback helps refine accuracy and relevance over time.
</Accordion>
